# Flutter Data Models & ListView Lab

Welcome to the Data Models and ListView practice lab! In this exercise, you will learn how to create a custom data class (Model) and use a `ListView.builder` to dynamically display a list of those objects on the screen.

## 🚀 Getting Started

1. Clone this repository to your local machine.
2. Run `flutter pub get` to ensure all dependencies are fetched.
3. Open the project in your IDE.

## 📝 Your Tasks

Search for the `TODO` comments in the `lib` folder and complete the missing code. 

*   **TODO 1 & 2 (`lib/models/book_details.dart`):** Declare the properties for your data model.
*   **TODO 3 (`lib/models/book_details.dart`):** Create a constructor to initialize the data.
*   **TODO 4 (`lib/main.dart`):** Populate a List with multiple instances of your data model.
*   **TODO 5 & 6 (`lib/main.dart`):** Connect your data list to the `ListView.builder` and display each item inside a `ListTile`.

## ✅ Expected Output
When you run the app, you should see a scrollable list of books. Each row should show the book's title on the left and the author on the right. Tapping on a book should print its title to your debug console.
